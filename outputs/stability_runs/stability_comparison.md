## Interpretation

Position-wise exact comparison is not used as the primary stability measure because LLM segmentation can split or merge adjacent semantic sections. Transcript-range overlap provides a more meaningful comparison.

The repeated runs show stable coverage of the same transcript regions, while topic labels and granularity can vary between runs.
