# DepoIndex

AI-Powered Deposition Topic Index

## Objective

DepoIndex is designed to identify meaningful topics and topic
transitions from deposition transcripts while preserving exact
page and line provenance.

## Planned Pipeline

PDF → Transcript Extraction → Provenance Preservation
→ Topic Segmentation → LLM Processing
→ Boundary Refinement → Provenance Validation
→ Topic Index → Evaluation
